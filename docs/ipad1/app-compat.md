## Pulling apps from legacystore.app

`legacystore.app` is the preservation archive (Sam's `jangle` repo): a browsable catalog
of early-App-Store apps whose binaries live on the Internet Archive. The site is a
**redirector, not a host** — `GET /ipa/<ipa_id>` returns a 302 to an `archive.org`
download URL, and `GET /manifest/<ipa_id>.plist` returns an `itms-services` OTA manifest
for install-on-device. Metadata (bundle id, version history, `MinimumOSVersion`, icons) is
in its Supabase DB and shown on `app/<id>` detail pages. Archived filenames encode the
facts we filter on: `Name-(bundleid)-version-(iOS_x.y)-<md5>.ipa`.

How we'd pull one for this compat pass:
1. Find a period-correct app+version on the site (or the archive.org item directly), noting
   `MinimumOSVersion <= 3.2` and iPad or iPhone family.
2. Fetch the single `.ipa` via `https://legacystore.app/ipa/<id>` (follows to archive.org)
   or the archive.org URL directly.
3. **Check it's decrypted** (`cryptid 0`) before use — `app-compat.py inventory <dir>` does
   this. This is the real gate: most archived App Store copies are original **FairPlay-
   encrypted** binaries, which the emulator cannot run (AppSync bypasses signing, not
   FairPlay). Only decrypted/cracked copies or developer builds install here.
4. Feed the decrypted `.ipa` to `app-compat.py run` (below).

No bulk downloads — pull individual IPAs on request. The 60 IPAs already in
`~/Downloads/ios3` are all decrypted and cover the candidate set for now.
